# 🥗 NutriFit

A complete, professional Flutter-based Nutrition and Fitness Web Application designed to help users manage their nutrition, workouts, fitness goals, and overall progress. NutriFit provides a modern and responsive interface with secure authentication, personalized health features, and AI-powered assistance.

## 🔗 Live Demo

[Check out the Live Demo Here!](https://nutrifit3005.web.app/)

## 🌟 Features

- **User Authentication**: Secure registration, login, and forgot password functionality using Firebase Authentication.
- **Nutrition Management**: Manage and track daily meals and nutrition-related activities.
- **Workout Tracking**: Track workouts and fitness activities to maintain a consistent routine.
- **Progress Tracking**: Monitor fitness and nutrition progress over time.
- **Personalized Goals**: Set and manage personalized health and fitness goals.
- **AI-Powered Assistance**: Get intelligent assistance and guidance related to nutrition and fitness.
- **Firebase Integration**: Secure authentication and cloud-based data management using Firebase.
- **Modern UI/UX**: Clean, intuitive, and responsive interface built with Flutter.
- **Cross-Platform**: Flutter-based application designed for multiple platforms.

## 🛠️ Tech Stack

- **Framework**: Flutter
- **Programming Language**: Dart
- **Authentication**: Firebase Authentication
- **Database**: Cloud Firestore
- **Storage**: Firebase Storage
- **AI Assistance**: AI-powered integration
- **Web Deployment**: Firebase Hosting

## 🚀 Installation & Setup

### 1. Clone the Repository

git clone https://github.com/sangeetha302005/nutrifit.git

cd nutrifit

### 2. Install Flutter Dependencies

Make sure Flutter and Dart are installed and properly configured on your system.

Run:

flutter pub get

### 3. Configure Firebase

Make sure the project is connected to the required Firebase project.

The application uses:

- Firebase Authentication
- Cloud Firestore
- Firebase Storage

Ensure the required Firebase configuration files and services are properly configured before running the application.

### 4. Run the Application

Run the Flutter application using:

flutter run

### 5. Run the Web Version

To run NutriFit as a web application:

flutter run -d chrome

The application can then be opened in the browser.
